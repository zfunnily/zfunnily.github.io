🛠 用 FRP 解决远程访问难题：从安装到使用的最简指南

在远程办公、远程维护设备已经成为常态的今天，我们常常会遇到一个头疼的问题：

明明家里有公网 IP，为什么在公司却连不上家里的电脑？ 为什么公司电脑没有公网 IP，我在外面就远程不了？

很多人以为需要拉专线、开 VPN、改路由，其实根本没那么复杂。 **FRP（Fast Reverse Proxy）**就是为这种“内网穿透 + 远程访问难题”而生的。

🎯 我遇到的问题：如何在家远程访问公司电脑？

我家里有公网 IP，但公司的电脑属于内网，没有对外开放端口。 传统方案都很麻烦：

  • VPN 公司不一定给开
  • 端口映射公司网络不允许
  • 第三方内网穿透有费率、稳定性问题

于是，最简单、最适合个人的方案 —— FRP，走进我的视野。

🚀 FRP 是什么？

一句话：

FRP 是一个内网穿透工具，让你远程访问处在内网的设备。

它通过公网服务器作为中转，让能访问本来不对外暴露的电脑、服务、摄像头、NAS 等。

我的场景是反向的：

  • 家里（有公网 IP）→ 作为 FRP 服务器
  • 公司（内网）→ 作为 FRP 客户端

🧩 FRP 如何解决问题？

用实际需求举例：

  • 在家运行 FRPS（服务端），家里有公网 IP，不需要租服务器
  • 公司电脑运行 FRPC（客户端）
  • 公司电脑自动把远程桌面、SSH、文件服务等 “映射” 回你家
  • 在外面直接访问：
公网IP:远程端口 → 就能连上公司的电脑

效果：

  • 不改公司网络配置
  • 不需要公网 IP（公司）
  • 稳定、可控、安全

✨ 1 分钟安装：FRP 最短命令教程

👨‍💻 家里电脑（服务端）

  1. 下载 FRP
  2. 编辑 frps.ini：
[common]
bind_port = 7000

注意：

  • 确保 7000、7500 端口未被占用
  • 防火墙允许这两个端口的流量
  1. 启动：
$ ./frps -c frps.ini

🖥 公司电脑（客户端）

1 .下载 FRP

  1. 写 frpc.ini（以远程桌面为例）：
[common]
server_addr = 家里公网IP
server_port = 7000

[rdp]
type = tcp
local_ip = 127.0.0.1
local_port = 3389
remote_port = 6000

注意：

  • 确保家里(公网IP) 6000 端口未被占用
  • 防火墙(公网)允许这两个端口的流量
  1. 启动：
$ ./frpc -c frpc.ini

现在你用windows自带的远程桌面连接：

  • 家里公网IP:6000
  • 打开方式是 win-> cmd -> mstsc -> 输入 家里公网IP:6000

即可直连 公司电脑的远程桌面。

📌 FRP 的典型应用场景

  • 家里远程公司电脑
  • 家里 NAS、软路由、摄像头远程访问
  • 远程维护客户仓库、工控机（业务里常见）
  • 多地服务器互联
  • 跨区域部署的监控系统接入

可以根据实际需求扩展多端口，支持 SSH、RDP、VNC、Web、数据库等各种服务。

🧱 小结：用 FRP，把复杂的远程访问问题变简单

只要有一个公网 IP（比如家里）， 就能把任何地方的内网电脑“拉到你手边”。

FRP 的优势：

  • 免费
  • 易部署
  • 稳定
  • 可扩展
  • 控制权完全在自己手里

如果你也正在为远程访问头疼，不妨试试 FRP，十分钟搭建，一个命令解决。

我自己的设置方式

  1. 在家里的电脑上运行 FRPS
  2. 在公司的电脑上运行 FRPC(含客户端界面, 可以作为服务运行)
  3. 配置 frpc.ini，映射需要的服务端口
  4. 启动 FRPC
  5. 在家里的电脑上访问 公网IP:远程端口，即可直连公司电脑的服务
  6. 家里路由器设置。
    • 确保 7000 端口映射到公司电脑的 7000 端口（FRPS）
    • 确保 6000 端口映射到家里电脑的 6000 端口, 会转发到公司电脑的 3389 端口（远程桌面）

FRP链接

  • FRP地址(命令行)：https://github.com/fatedier/frp
  • FRP(含客户端界面, 可以作为服务运行)： https://github.com/koho/frpmgr/releases
